Support

We're an independent studio — support is personal, honest, and best-effort.

Get help

  • Email: olivermasson7@hotmail.com — bug reports, feature requests, questions, template requests. Include your panel's JS and the exact error message when reporting widget issues.

Response times

Responses typically within 2 business days, Monday–Friday, 9:00–17:00 CET. Best effort — no SLA.

Reporting a security issue

Please email olivermasson7@hotmail.com with "SECURITY" in the subject rather than opening a public issue. Reports are acknowledged and triaged promptly; fixes ship via Forge's versioned deploy flow, which requires no customer action for same-permission updates.

Before you write in

  • Check the documentation — especially the bridge API reference and the writable-fields / embed-domains permission model.
  • A write showing "Write blocked: field … is not in this panel's writable fields" means exactly that — add the field id to the panel's Writable fields box and save.
  • Panel changes are picked up when an issue view loads — refresh the issue after saving a panel.
